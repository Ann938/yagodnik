# Ягодник — концепт-лендинг мороженого (портфолио)

Вымышленный бренд мягкого мороженого в вафельном рожке (сеть киосков), три вкуса: клубника, малина, ежевика.
Лого — ягода из зёрнышек с листиками (`Logo` в Landing.tsx, `public/favicon.svg`).
Референс механики (не копировать оформление): pirojnikoff-zefir.vercel.app — продукт и летающие ингредиенты.

- Next 16 + SCSS-модули, `u()` из `src/styles/_core.scss` (ДВ 1440 / контент 1280; МВ ≤1023 — колонка 358).
  Шрифты: Unbounded (заголовки) + Manrope. Тексты — `src/content.ts`, у вкуса своя палитра (bg/bg2/ink/accent).
- Рожок (сейчас, по выбору пользователя) — версия коммита adaef56: 4 ракурса с листа клубники «Четыре ракурса ванильного рожка
  с клубничным джемом.png», джем малины/ежевики перекрашен (палитра по яркости с её фото), постоянное вращение 0.35 рад/с,
  смешение ракурсов cos^10. Атласы `public/cone/atlas-<вкус>.webp` + `src/three/profile.json` — из того коммита
  (скрипт сборки той версии — `git show adaef56:scripts/build-cone.py`; текущий build-cone.py — для родных листов по вкусу).
  Запасные состояния: метка `backup-cone-sway-front-hd` (родной джем с трёх листов, лицо в 2x, только покачивание −13°…0°),
  метка `backup-single-photo-cone` (одно фото на вкус).
  Смена вкуса — новый атлас проступает поверх старого. Экран загрузки — `Preloader.tsx` (ждёт `yg:ready`).
  Позы — `POSES` в Cone3D.ts; на МВ рожок встаёт в `[data-cone-spot]` / `[data-flv-spot]`.
- Ягоды — настоящие фото с удалённым фоном (`public/fruit/*.webp`, rembg isnet), `Fruits.tsx`: два слоя — за рожком и перед ним (размытые); в блоке вкусов зеркалятся за рожком; ниже блока вкусов скрыты.
  Источник: Wikimedia Commons, Ivar Leidus (CC BY-SA 4.0) — атрибуция в подвале обязательна.
- Фон: свечение за рожком и зерно (`.backdrop`). Переключатель вкусов на первом экране — вертикальная колонка справа (`.rail`), на МВ — строка под рожком.
- Хореография: ScrollTrigger'ы в `Landing.tsx` пишут в `src/three/stage.ts`, сцена читает каждый кадр. 
- «Киоски» — `Find.tsx` + `cityMaps.ts` (координаты) + `mapStyle.ts`: настоящая карта MapLibre GL, тайлы OpenFreeMap (OSM),
  свой стиль — обычная серая карта (не в цвет вкуса, так попросила пользователь). Воркер — `public/vendor/maplibre-gl-worker.mjs` (копия из
  node_modules, обновлять вместе с пакетом). Метки-логотипы связаны с белой панелью списка; метка/строка → Яндекс Карты,
  кнопка и клик по карте → 2ГИС города. Колесо листает страницу (scrollZoom выкл.), карту тянут мышью/пальцем, подсказок поверх карты нет. Порядок вкусов: клубника, ежевика, малина (чтобы красные не шли подряд).
- Смена вкуса: волна новой заливки (`.wave`) поднимается снизу, под ней меняются CSS-переменные.
- Проверка: `npx next dev -p 3500`; `node scripts/shots.mjs <out> [w h]` (нужен PW_CHROME; swiftshader медленный — сцена в скриншотах может отставать от скролла).
